# Pack queue — berçário de packs

Referências visuais APROVADAS pelo Gustavo aguardando virar pack (`gp3/packs/<slug>/`).
Cada imagem aqui é uma candidata a `reference.png` de um pack futuro — a curadoria
que era o "golden set" do bt, repropositada: no gp3 a âncora de fidelidade é o
`reference.png` do próprio pack, e a régua de entrada é a certificação humana.

Fluxo: garimpo (pins/Behance/vencedores excepcionais) → aprovação do Gustavo →
entra aqui → extração de pack (tokens + recipes) → certificação → fábrica.

Só o Gustavo adiciona/remove.
