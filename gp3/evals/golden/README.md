# Golden set — guia de curadoria (30 min do Gustavo)

Screenshots 1080×1350 (ou proporção 4:5), nomeados `<familia>-<eixo-que-ancora>-<n>.<ext>` (ex: `editorial-clinico-scrollstop-1.png`, `premium-minimal-continuidade-1.jpg`). Alvo: 10–20 imagens. **Só humano adiciona/remove aqui** (aprovação do Gustavo; o agente prepara candidatos em `_staging/`).

## De onde tirar (em ordem de facilidade)

1. **Conversões do Claude Design** que você já fez (Pocs/claude_design_to_fabric) — abra no editor, screenshot dos slides que você considera nível estúdio.
2. **Instagram**: 3–5 contas brasileiras de saúde/estética com design excepcional (agências, clínicas premium). Screenshot do slide 1 + 1 slide de miolo dos melhores carrosséis. Uso interno como âncora de avaliação.
3. **Vencedores da própria pipeline**: quando um template sair excepcional (score ≥42/50 E você concordar), promova o screenshot pra cá.

## Critério de entrada (por eixo da rubrica)

Só entra se você responderia "sim" a pelo menos 4:
- O slide 1 pararia SEU scroll?
- Parece feito por estúdio para aquele nicho específico?
- A hierarquia se entende em 1 segundo?
- Tem um elemento de identidade memorável (não é template de Canva)?
- Você pagaria por esse design?

## Distribuição desejada

- ≥2 exemplares por família estética que a pipeline mais usa (editorial clínico, premium minimal, soft wellness, bold educacional).
- ≥3 capas (slide 1) — o eixo scroll-stop é o de maior peso.
- ≥1 slide de CTA bem resolvido.

Enquanto esta pasta estiver vazia, o judge avalia sem âncora (score tende a inflar) — o `JUDGE.md` manda ele reportar "golden set ausente" no relatório para você lembrar.
