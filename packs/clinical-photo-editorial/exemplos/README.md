# Exemplares — clinical-photo-editorial

## miolos/ — esqueletos de composição (fallback)

`esqueletos.html` é uma fita renderizável com as seis composições de miolo
documentadas na tabela do `tecnicas.md`. Para ver:

```
node engine/assemble.js packs/clinical-photo-editorial/exemplos/miolos/esqueletos.html <outdir>
```

E1–E5 são slides independentes; **E6a + E6b são um par** — a foto atravessa a
emenda pela `.fita-layer` e só faz sentido junto (`E6-par.jpg` mostra os dois
lado a lado).

As fotos (`foto-*.jpg`, `decor.png`) são de teste, reaproveitadas de uma run —
existem só para o arquivo renderizar. **Produção gera assets próprios por post.**

São ponto de partida, nunca fôrma: duas fitas com o mesmo esqueleto continuam
sendo defeito.

## Histórico

`fita-aprovada-gram-teste-1` foi removida em 2026-08-08. Era o único exemplar de
fita completa e carregava os defeitos que a fábrica vinha reproduzindo (miolo
com texto solto no branco, bloco chapado com vão, cartão superdimensionado) — o
agente copiava fielmente o que estava marcado como aprovado. O
`certification/cert-fibro-1-judge-report.md` ainda a cita: é registro histórico
do julgamento daquela data e não deve ser reescrito.
